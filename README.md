# OMNIA — protótipo funcional

Protótipo front-end navegável inspirado nas telas fornecidas.

## Como executar
1. Abra `index.html` diretamente no navegador, ou
2. Para servir localmente:
   ```bash
   python -m http.server 8080
   ```
   e acesse `http://localhost:8080`.

## Funcionalidades implementadas
- Início com upload por clique ou drag-and-drop.
- Criação de nova reunião.
- Tela de análise/transcrição com riscos, oportunidades e recomendações.
- AI Copilot (Nabu) com perguntas rápidas e respostas simuladas.
- Dashboard do colaborador com gráficos e indicadores.
- Páginas de Insights, Clientes, Oportunidades, Riscos e Relatórios.
- Exportação de relatório CSV.
- Configurações e modo compacto.
- Layout responsivo.

## Observação
É um protótipo funcional front-end sem backend real. Os dados e respostas de IA são demonstrativos. Para produção, conecte APIs, autenticação, banco de dados e serviço de IA.
